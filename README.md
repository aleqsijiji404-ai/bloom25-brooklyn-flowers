## 🚀 GitHub-ზე და Vercel-ზე გაშვების ინსტრუქცია (Deployment)

### 1️⃣ პროექტის გითჰაბზე (GitHub) ატვირთვა:
თუ უკვე გაქვთ GitHub ანგარიში, გახსენით ბრძანებათა სტრიქონი (Terminal) ამ საქაღალდეში და გაუშვით:

```bash
# 1. შეიყვანეთ თქვენი GitHub რეპოზიტორიის ბმული
git remote add origin https://github.com/YOUR_USERNAME/bloom25-brooklyn.git

# 2. ატვირთეთ კოდი GitHub-ზე
git branch -M main
git push -u origin main
```

*(თუ ჯერ არ გაქვთ რეპოზიტორიი შექმნილი, შედით [github.com/new](https://github.com/new), დარქმით სახელად `bloom25-brooklyn` და შექმენით empty repository).*

---

### 2️⃣ Vercel-ზე უფასოდ გაშვება (1-Click Deployment):

1. შედით [vercel.com](https://vercel.com) საიტზე და გაიარეთ ავტორიზაცია თქვენი GitHub ანგარიშით.
2. დააჭირეთ ღილაკს **"Add New..." -> "Project"**.
3. აირჩიეთ თქვენი `bloom25-brooklyn` რეპოზიტორიი list-იდან.
4. დააჭირეთ **"Deploy"**!
5. **მორჩა!** Vercel 10 წამში მოგცემთ მზა უფასო ლინკს (მაგ: `https://bloom25-brooklyn.vercel.app`), სადაც საიტი 24/7 იფუნქციონირებს.
